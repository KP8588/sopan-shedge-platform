# Sopan Shedge Platform

A learning and live-class platform for students and trainers.

## Planned Technology

- Student mobile app: Flutter
- Admin and trainer dashboard: Next.js and TypeScript
- Backend: Django REST Framework
- Database: PostgreSQL
- Cache and task coordination: Redis
- Live classes: LiveKit and WebRTC
- AI services: Python speech recognition, translation and text-to-speech
- Deployment: Docker Compose

## Development Milestone

Target MVP launch: 28 October 2026.

## Project Structure

- `student_app/` - Flutter application
- `admin_web/` - Web dashboard
- `backend/` - Backend API and application modules
- `ai_service/` - Speech and translation services
- `infra/` - Container and deployment configuration
- `docs/` - Architecture, API and setup documentation

## Security

Keep real credentials in local environment files.
Never commit API keys, passwords, private keys or production secrets.
